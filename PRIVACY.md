# Privacy

Ultimate Humanizer is a Claude Code skill (a set of instructions) and a local Python script, `scripts/lint.py`.

- The author collects, receives and stores no data from you. There is no server, account, telemetry or analytics.
- `scripts/lint.py` runs on your machine. It uses only the Python standard library and makes no network calls. It reads the file or stdin you give it and prints results.
- The skill sends nothing anywhere itself. Text you give Claude while using the skill is handled by Anthropic under your own Anthropic terms and privacy policy.
- The optional install scripts (`scripts/install.sh`, `scripts/install.ps1`) and the `git clone` and `pip install` routes download this repository from GitHub. GitHub handles those requests under its own terms.

Contact: open an issue at https://github.com/DrARaj/ultimate-humanizer/issues.
