# Prompts used for the AI set

Each passage was generated by one call, run from a neutral temp folder so no project instructions were in context:

```
claude -p --model haiku "Write one encyclopedic paragraph of about 150 words about <topic>."
```

`<topic>` is the Wikipedia article title for the matching human-wiki passage (see `manifest.csv`, column `topic`). The prompt does not mention AI tells and does not ask the model to avoid or include any. The model alias `haiku` resolved to whatever Claude Haiku version the Claude Code install served on the retrieval date in the manifest.

Call count: 42, not 40. Two topics were swapped after the first pass because the Wikipedia side failed (Mitochondrion was a redirect before 2022, and Wangari Maathai had no revision before 2022 under that title). The passages for the two dropped topics were deleted; the 40 in `data/` are the final set.
