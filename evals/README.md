# Lint evaluation

Measures how often `scripts/lint.py` flags human-written text (false alarms) compared with AI-written text. Results are in [RESULTS.md](RESULTS.md) and `results.json`.

## Reproduce

From the repo root, Python 3 and the standard library only for the first two steps:

```
python evals/run_eval.py          # lint every file in evals/data, write results.json and RESULTS.md
python -I scripts/lint.py evals/RESULTS.md   # quoted example lines are expected to FAIL
```

`run_eval.py` needs only the committed data. To rebuild the data from scratch (network, and the Claude Code CLI for the AI set):

```
python evals/fetch_data.py        # 40 Wikipedia paragraphs + 20 arXiv abstracts
python evals/gen_ai.py            # 40 passages via `claude -p --model haiku`, then merges manifest.csv
```

The AI step uses your Claude Code login and counts against its usage. Regenerating gives new AI text, so the numbers will move a little. The prompt is in [prompts.md](prompts.md).

## Data

One passage per `.txt` file in `data/`, 80 to 250 words. `data/manifest.csv` has id, set, source_url, licence, retrieved, topic, words.

| Set | Source | Licence |
|---|---|---|
| human-wiki (`wiki01`..`wiki40`) | English Wikipedia revisions dated before 2022-01-01; each URL carries the `oldid` | CC BY-SA 4.0 (attribute Wikipedia contributors, share alike) |
| human-abstracts (`abs01`..`abs20`) | arXiv abstracts submitted 2015 to 2020, via the export.arxiv.org API | arXiv metadata is CC0 |
| ai (`ai01`..`ai40`) | Generated by Claude Haiku through `claude -p`, one per human-wiki topic | Generated text; no claim made |

Edits to the source text: Wikipedia citation markers such as `[1]` were stripped, line breaks collapsed to spaces, and only plain prose paragraphs were kept (no lists, tables, infoboxes or references). Nothing else was changed.

The Wikipedia passages are CC BY-SA 4.0 and stay under that licence; the repo's code is MIT (see the main README).
